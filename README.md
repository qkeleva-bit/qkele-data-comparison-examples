# QKELE Data Comparison Examples

Example datasets and methodology for comparing business data, identifying meaningful changes, and tracing differences to evidence.

## What this repository demonstrates

Business data often changes between reporting periods.

A comparison may reveal:

- Added records
- Removed records
- Changed values
- Multiple related changes
- Changes that may require investigation

The examples in this repository demonstrate how these changes can be represented and investigated.

## Example scenario

Imagine two versions of a company's sales data.

The current dataset may contain:

- New products
- Removed products
- Changed prices
- Changed quantities
- Changed revenue values

A basic comparison can identify the differences.

A business investigation goes further by asking:

- Which changes are significant?
- Which changes are related?
- What caused the change?
- Where is the supporting evidence?
- What should be investigated next?

## QKELE

QKELE is a business data investigation and comparison platform.

QKELE compares versions of business data and documents, identifies additions, removals, and changed values, prioritizes meaningful findings, connects related changes, and traces findings back to their underlying evidence.

Its core comparison engine is deterministic, with optional AI assistance used as an advisory layer for investigation and explanations.

Website: https://qkele.app
